# 银川科技学院（海旗）学习与测评助手 Pro

> 🔴 **警告：本项目仅作为 JavaScript / Tampermonkey 用户脚本编程学习演示，严禁在 `ycust.haiqikeji.com` 真实网课平台使用。使用脚本造成账号限制、学校纪律处分，一切责任由使用者自行承担。**

## 项目介绍

针对银川科技学院海旗网课平台 `https://ycust.haiqikeji.com/*` 的油猴（Tampermonkey）演示脚本。
模拟实现视频倍速播放、弹窗自动关闭、章节自动切换、测评页面模拟答题等前端功能；**仅用于技术研究，不保证线上可用性，不建议实际运行。**

## 功能特性

- 视频模块
  - 自定义播放倍速，支持强制锁定倍速
  - 拦截平台进度回拽看门狗逻辑
  - 自动关闭课程弹窗提示、屏蔽快进警告弹窗
  - 视频播放结束自动切换下一章节
  - 视频自动静音
- 测评答题模块
  - 多种答题策略：第一项 / 最后一项 / 中间项 / 随机
  - 自动识别开始、下一题按钮
  - 默认关闭自动交卷，防止误操作提交试卷
- 悬浮控制面板
  - Shadow-DOM 隔离 UI，不被页面样式干扰
  - 可视化开关全部功能，一键启动 / 停止

## 环境依赖

- 浏览器 Chrome / Edge / Firefox
- 浏览器扩展：**Tampermonkey（油猴脚本管理器）**

## 脚本安装方式

1. 浏览器安装 Tampermonkey 扩展；
2. 复制仓库内 `ycust_haiqikeji_helper.user.js` 的全部源码；
3. 打开油猴面板 → 新建脚本，粘贴全部代码，Ctrl+S 保存；
4. 访问 `https://ycust.haiqikeji.com/*`，页面右上角弹出控制面板代表加载成功。

> 脚本仅匹配域名：`ycust.haiqikeji.com` 及海旗子域名。

## 使用说明

1. 进入网课播放页面，页面右侧出现悬浮控制台面板；
2. 设置倍速、答题策略，按需勾选开关；
3. 点击【刷课】启动视频处理；点击【答题】启动测评处理；点击【停止】终止脚本循环；
4. ⚠️ 不要开启自动交卷，避免考试误提交。
